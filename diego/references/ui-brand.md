# Diego — UI Brand Guide

## Banners
```
╔═══════════════════════════════════════════════╗
║  DIEGO — Phase {N}: {Name}                   ║
╚═══════════════════════════════════════════════╝
```

## Section Headers
```
─── Phase 01: Foundation ──────────────────────
─── Planning ──────────────────────────────────
─── Execution ─────────────────────────────────
─── Verification ──────────────────────────────
```

## Status Symbols
- `✓` — completed / success
- `⟳` — in-progress
- `○` — pending
- `✗` — failed
- `⚡` — fast mode (default)
- `🔍` — thorough mode

## Progress Bars
```
[████████░░░░] 66% — Phase 2 of 3
[████████████] 100% — All plans executed
```

## Agent Labels
```
[PLANNER]   — diego-planner
[EXECUTOR]  — diego-executor
[VERIFIER]  — diego-verifier
[RESEARCHER]— diego-researcher
[MAPPER]    — diego-mapper
[DEBUGGER]  — diego-debugger
```

## Checkpoint Markers
```
◆ CHECKPOINT: {description}
◇ DECISION: {choice made}
● ACTION: {action taken}
⊘ GATE: {skipped in fast mode}
```

## Output Format
- **Fast mode (default):** Compact, minimal output. Show results, skip narration.
- **Thorough mode:** Verbose. Show reasoning, evidence, alternatives considered.

## Color Conventions (terminal)
- Green: success, completion
- Yellow: warning, in-progress
- Red: error, failure
- Cyan: informational, navigation
- Dim/gray: metadata, timestamps
